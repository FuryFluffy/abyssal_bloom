# Generation Notes

- Keep prompts short. SD1.5/AOM3 responded poorly to the earlier overlong prompt set.
- Put **pose/state first**, then enemy identity, then only essential costume/weapon traits.
- For attack/hurt states, explicitly suppress idle/neutral poses in the negative prompt.
- Avoid baked VFX wherever possible. Add attack trails, spell effects, blood/impact effects, and status effects separately in Godot.
- With the revised workflow, use:
  - **IP-Adapter** for approved identity/reference image;
  - **OpenPose ControlNet** for body pose;
  - AOM3 + prompt for the final sprite rendering.
- For strongly non-humanoid enemies such as Cell Slime, pose ControlNet should be weak or omitted.
- For The Jailer and other unusually large/architectural enemies, use OpenPose only as loose guidance if it improves composition.
